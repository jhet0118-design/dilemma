# 딜레마 교실

로그인 없이, 각자 기기로 참여하는 실시간 죄수의 딜레마 교실 게임입니다.
Next.js + Vercel KV(Redis)로 만들어져 있어서, 학생들은 회원가입 없이 4자리
코드와 별명만으로 참여하고, 서버(Vercel)를 거쳐 실제로 실시간 동기화됩니다.

## 배포 방법 (처음 한 번만)

### 1. GitHub에 올리기

이 폴더에서:

```bash
git init
git add .
git commit -m "딜레마 교실 초기 커밋"
```

GitHub에서 새 저장소(예: `dilemma-classroom`)를 만든 뒤:

```bash
git remote add origin <새로_만든_저장소_주소>
git branch -M main
git push -u origin main
```

### 2. Vercel에 배포하기

1. https://vercel.com 대시보드 → **Add New → Project**
2. 방금 만든 GitHub 저장소를 선택 → **Deploy** (설정은 기본값 그대로 두면 됩니다)
3. 첫 배포가 끝나면, 그 프로젝트의 **Storage** 탭으로 이동
4. **Create Database → KV (Redis)** 선택 → 만든 뒤 이 프로젝트에 **Connect**
   - 이 과정에서 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 같은 환경 변수가 프로젝트에 자동으로 추가됩니다.
5. **Deployments** 탭에서 방금 배포를 다시 한번 **Redeploy** 해주세요 (환경 변수가 적용되려면 재배포가 필요해요).

이제 Vercel이 알려주는 주소(`https://your-project.vercel.app`)가 학생들에게 공유할 링크입니다.
로그인도, 앱 설치도 필요 없이 그 링크를 열기만 하면 됩니다.

## 로컬에서 테스트하기

```bash
npm install
npx vercel link        # 방금 만든 Vercel 프로젝트와 연결
npx vercel env pull .env.development.local   # KV 환경 변수를 로컬로 가져오기
npm run dev
```

`http://localhost:3000` 에서 여러 브라우저 탭(또는 시크릿 창)을 열어 선생님/학생 역할을
동시에 테스트해볼 수 있어요.

## 게임 흐름

- **선생님**: 라운드 수 · 짝 배정 방식(고정/무작위) · 라운드 제한 시간 · 점수표를 정하고 게임을 만들면 4자리 코드가 생성됩니다.
- **학생**: 코드 + 별명만 입력하면 대기실로 들어갑니다.
- 선생님이 시작하면 서버가 짝을 배정하고, 각 학생은 자기 기기에서 협력/배신을 선택합니다. 학생들은 라운드 중에도, 마지막 결과가 나올 때까지도 서로 누구와 짝이 되었는지 알 수 없습니다(선생님 화면에는 실제 이름이 보입니다).
- 짝의 선택이 모두 들어오면(둘 다 제출하면) 서버가 즉시 점수를 계산해 결과를 공개하고, **자동으로 다음 라운드로 넘어갑니다.** 제한 시간을 넘겨도 선택하지 않은 학생은 자동으로 "배신"으로 처리됩니다. (선생님은 언제든 수동으로 다음 라운드 버튼을 눌러 넘길 수도 있습니다.)
- 인원이 홀수면 한 명은 컴퓨터와 대결합니다.
- 선생님 화면에는 실시간으로 각 학생의 누적 점수, 라운드 진행 상황, 제출 현황이 표시됩니다.
- 마지막 라운드 후 전체 순위표(이름 · 협력 횟수 · 배신 횟수 · 총점)가 모두에게 공개됩니다.

## 참고

- 세션 데이터는 생성 후 6시간이 지나면 자동으로 만료됩니다 (`lib/game.js`의 `TTL_SECONDS`).
- 코드에 별도의 인증/보안 장치는 없습니다 — 교실 안에서, 짧은 시간 동안 쓰는 걸 전제로 만들어졌어요.
